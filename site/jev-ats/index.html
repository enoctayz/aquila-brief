TYPED JUDGMENT · RESUME SCREENING

Screening resumes with typed answers

An LLM that writes prose is hard to audit. Jev only answers typed questions: a probability, a level on a scale, a pick from a list. Our code turns those answers into reject / pass / fail.

  • model jev-latest
  • api TypeSafe systemone
  • stack FastAPI · pypdf
  • rubrics 6 roles · JSON

Key finding

Score each resume alone, compare them together.

A candidate's score must not depend on who else applied.

Design choice Why Effect
One request per resume No anchoring on others 6 scores independent
Same call ×5, mean Jev is sampled at most 0.10 max run spread
Knockouts before score Hard requirements win 4 / 6 rejected
